# USE CASE: 4 Produce a Report on the Salary of Employees in a Department

## CHARACTERISTIC INFORMATION

### Goal in Context

As an *Department Manager* I want *to produce a report on the salary of employees in my department* so that *I can support financial reporting of the organisation.*

### Scope

Company.

### Level

Primary task.

### Preconditions

We know the role.  Database contains salary data for employees in each department.

### Success End Condition

A report is available for the Department Manager to provide to finance.

### Failed End Condition

No report is produced.

### Primary Actor

Department Manager.

### Trigger

A request for finance information is sent to the Department Manager.

## MAIN SUCCESS SCENARIO

1. Finance request salary information for employees in a specific department.
2. Department Manager inputs name of his department to get salary information for it.
3. Department Manager extracts salary information of all employees in his department.
4. Department Manager provides report to finance.

## EXTENSIONS

None.

## SUB-VARIATIONS

None.
